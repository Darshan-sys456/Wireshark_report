# WIRESHARK PROTOCOL ANALYSIS REPORT

## 1. Introduction

Wireshark is an open-source network protocol
analyzer used to capture, inspect and analyze
network traffic.

It helps network administrators and cybersecurity
professionals understand communication between
devices.

## 2. Objectives

- Study different networking protocols.
- Understand packet transmission.
- Analyze network communication.
- Identify suspicious network activities.
- Understand protocol headers.
- Perform packet analysis using Wireshark.

## 3. OSI Model

| Layer | Name | Protocol Examples |
|---|---|---|
| 7 | Application | HTTP, DNS, FTP |
| 6 | Presentation | TLS, Encoding |
| 5 | Session | Session Management |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP, ICMP, OSPF |
| 2 | Data Link | Ethernet, ARP |
| 1 | Physical | Cables, Signals |

## 4. What is Packet Analysis?

Packet analysis is the process of capturing and
examining network packets to understand
communication between devices.

Wireshark provides three major sections:

1. Packet List
2. Packet Details
3. Packet Bytes

## 5. Protocol Analysis

Protocols define rules for communication
between network devices.

Major protocol categories include:

- Ethernet
- ARP
- IPv4
- IPv6
- TCP
- UDP
- ICMP
- DNS
- DHCP
- HTTP
- HTTPS
- TLS
- FTP
- SSH
- SMTP
- SNMP
- SMB
- NTP
- SIP
- RTP

Detailed protocol information is available
in PROTOCOL_CATALOG.md.

## 6. Packet Analysis Workflow

1. Open Wireshark.
2. Select a network interface.
3. Start packet capture.
4. Generate network traffic.
5. Stop packet capture.
6. Apply display filters.
7. Inspect packet headers.
8. Analyze communication.
9. Document observations.

## 7. Security Applications

Wireshark can help investigate:

- Suspicious network connections
- DNS anomalies
- Unexpected cleartext traffic
- TCP retransmissions
- Network scanning indicators
- Authentication failures
- Unusual traffic patterns

## 8. Conclusion

Wireshark is an important tool for networking
and cybersecurity.

Understanding network protocols and packet
structures helps troubleshoot connectivity,
analyze network performance and investigate
security incidents.
