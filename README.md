# Wireshark Protocol Analysis

## Project Overview
This project provides comprehensive documentation
and practical analysis of network protocols using
Wireshark.

## Objectives
- Understand network protocols.
- Study OSI and TCP/IP models.
- Analyze network packets.
- Understand TCP, UDP, DNS, HTTP, DHCP, ARP, etc.
- Identify network errors and security threats.
- Learn Wireshark display filters.

## Protocol Categories

1. Network Layer Protocols
2. Transport Layer Protocols
3. Application Layer Protocols
4. Security Protocols
5. Routing Protocols
6. Wireless Protocols
7. Industrial Protocols

## Tools Required
- Wireshark
- Windows / Linux
- Sample PCAP files
